One line, under 200 characters, that gets you out of work and gets a laugh:
a sick-day excuse a boss might half believe and a coworker would quote all
week. The program writes the excuse to `entry.txt` — nothing else.

## Run it

```sh
python3 main.py
```

It writes the line (no trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), after validating it
against the gate: 1–200 characters, a single line, non-blank, valid UTF-8.
